Program 0: Prompt user if he has an account already - DONE

Program 1: Sign up - DONE
1. Prompt user for username and pin password
2. If user inputs words in the password, go back to step 2; else tell user the account has been created

Program 2: Log in 
1. Prompt user for valid and existing username and pin password
2. If valid, proceed to program 3

Program 3: Prompt user either for program 4, 5, or 6 //another inside if statement of program 2
1. Prompt user what to do: If user inputs deposit, go deposit; else if user inputs withdrawal, go withdrawal; else if check account balance; else log out

Program 4: Deposit
1. Prompt user how much to deposit in dollars
2. Scan if user has that ammount of money; if yes proceed to 3; if no go back to 1
3. If user input words, print out invalid input; else print out deposited successfully 

Program 5: Withdrawals
1. Prompt user how much to withdraw
2. If user inputs words, print out invalid input
3. Else scan the user input if the money to be withdrawn is valid
4. If user inputs too much value or a non-existent value, print out not enough cash!
5. Else print out withdrawn successfully, and then assign 0 to the constant array of deposit

Program 6: 
1. Print out the account balance
