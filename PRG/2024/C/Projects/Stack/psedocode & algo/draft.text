Push: This inputs values to the stack/array - 1
1. Initialize a relative data type function with parameter as long long integer.
2. Inside that function, initialize a an array using the pointer method with malloc with it's relative data type.
3. Assign a value to the first element of that array with the value of the long long integer.
3.1. In the second element of the array, assign a value of 1.
4. Return the array. 

Pop: This removes the latest value of the stack/array - 2
1. Initialize a relative data type pointer array with malloc with it's relative data type.
2. Assign the first element of that array to 0.
3. Assign the second element of that array with 2.
4. Return the array.

Clear: This removes all the value of the stack/array - 3
1. Create a function with int pointer as the return and no parameter
2. Initialize a pointer array with 0 as the first index and 3 in the second

Capacity: Checks the total elements that the stack can carry - 4
1. Initialize a function with int pointer as the return and no parameter
2. Initialize a pointer array with 0 as the first index and 4 in the second

Add: This adds value to the stack with a specified index 5
1. Initalize a function with int pointer with a parameter of value, and int index
2. Initalize a pointer array with the value as its first element, 5 as the second, and third as the index

Remove: This removes the value within a stack with a specified index - 6
1. Initialize a function with int pointer with a parameter of int index
2. Initalize a pointer array that takes the index as its first element and then assign a value of 6 to the second index

Peak: This shows or returns the latest value of the stack - 7
1. Initalizea function with int pointer without a parameter
2. Initialzie a pointer array that has zero as its first element and then assign a value of 7 to the second index

Search: This searches the value within a stack - 8
1. Initalize a function with int pointer with a parameter that takes a value
2. Initalize a pointer array that has value as its first element and then assign a value of 8 to the second index
